## 🔎 Overview — What Is *Liminal Vocal Textures Volume 2*?

*Liminal Vocal Textures Volume 2* is the second installment in Crocus Soundware’s celebrated series of ethereal, processed vocal phrases. Unlike static sample packs, this library is built around **morphing, layered, and time‑stretched vocal fragments** that exist in the “in‑between” — a liminal space between speech and music, tone and texture, human and machine.

Think of it as a **sonic fog machine** for your DAW: each sample is a breath, a whisper, a fragment of a word, stretched beyond recognition, then polished with analog warmth and digital sheen. Whether you’re scoring a psychological thriller, crafting ambient drone beds, or layering subtle vocal presence into a pop track, Volume 2 delivers **850+ individual WAV files** (24‑bit, 48 kHz) divided into five distinct categories:

- **Aetherial Drones** — Long, evolving pads built from slowed‑down, reversed vocal samples.
- **Fragmented Whispers** — Granular, glitchy particles of speech that scatter like leaves in wind.
- **Midnight Chorus** — Layered vocal clusters with harmonic ambiguity.
- **Rustling Breath** — Intimate, close‑mic’d exhalations with subtle movement.
- **Processed Phrases** — One‑shot phrases smeared with reverb, distortion, and spectral manipulation.

Each category includes both wet (processed) and dry (raw) variants, along with **Kontakt 7 / KSP instrument patches** that let you modulate parameters in real time. The result? A palette that feels less like a sample library and more like a living, breathing instrument.

Here’s a typical setup for integrating *Liminal Vocal Textures Volume 2* into an ambient/drone project:

```mermaid
graph TD
    A[DAW: Ableton Live 12] --> B[Kontakt 7.5+]
    B --> C[Liminal Vocal Textures Vol. 2]
    C --> D{Aetherial Drones}
    C --> E{Fragmented Whispers}
    C --> F{Midnight Chorus}
    C --> G{Rustling Breath}
    C --> H{Processed Phrases}
    
    D --> I[Output to Master Bus]
    E --> I
    F --> I
    G --> I
    H --> I
    
    I --> J[Valhalla VintageVerb (send FX)]
    I --> K[FabFilter Pro‑Q 3 (EQ cut at 300 Hz)]
    I --> L[Ozone 11 (limiter)]
    
    J --> M[Final Mixdown]
    K --> M
    L --> M
```

In this example, the library’s internal reverb is disabled (to avoid double processing) and instead routed through an external Valhalla VintageVerb on a send track. An EQ cut removes low‑mud frequencies below 300 Hz. The final limiter ensures a consistent‑6 dB headroom.

## 🤖 OpenAI API & Claude API Integration

This repository includes a **companion Python script** (`liminal_vocal_to_prompt.py`) that extracts metadata from the library and formats it for direct use with **OpenAI’s GPT‑4** or **Anthropic’s Claude** APIs. This is useful for generating sound‑design prompts, mixing suggestions, or even automatic labeling of new recordings.

### How It Works

The script reads the library’s embedded metadata (sample name, category, BPM, key, wet/dry flag, modulation assignments) and outputs a structured JSON block. You can then feed that JSON into an LLM with a prompt like:

> “Given the following parameters for a vocal texture sample, suggest three processing chains that would transform it into a horror soundtrack element: [JSON here]”

### Example Output (Truncated)

```json
{
  "sample_id": "ATD_0047",
  "category": "Aetherial Drones",
  "bpm": 60,
  "key": "C min",
  "length_sec": 24.8,
  "modulation_assignments": {
    "modwheel": "pitch_shift (-12 to +12 semitones)",
    "aftertouch": "filter_cutoff (200 Hz to 8 kHz)",
    "velocity": "reverb_send_amt (0 to 100%)"
  },
  "dry_wet_ratio": 0.5
}
```

### Requirements

- Python 3.9+
- `openai` or `anthropic` Python package (installed via `pip`)
- A valid API key (stored in environment variable `OPENAI_API_KEY` or `ANTHROPIC_API_KEY`)

The script is safe to run even if you don’t have an API key — it will print the JSON to stdout without making network calls. This is an **optional tool**, not a requirement for library use.
